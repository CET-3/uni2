¿Qué es esto?

Design System UNI2

Un design system es el conjunto de decisiones de diseño de un producto, documentadas y organizadas para que todo el equipo las use de forma consistente.

En lugar de inventar cada vez cómo se ve un botón, un color o una card, el design system define esas respuestas una sola vez. Todos los que construyen el sitio — diseñadores, desarrolladores, alumnos — trabajan desde el mismo punto de partida.

El design system de UNI2 está implementado en un único archivo CSS (uni2-design-system.css) y documentado en esta página.

La pirámide de capas

Cada capa se construye sobre la anterior. No se puede tener componentes sin primitivos, ni primitivos sin tokens.

La base de la pirámide son los tokens: los valores concretos que definen la identidad visual. Todo lo que está encima los usa, pero nunca los repite.

Sistema visual UNI2

Colores semánticos

Estos tokens cambian de valor entre el tema claro y el oscuro. Los componentes los usan en lugar de los colores de marca directos, para que el modo oscuro funcione automáticamente.

Django + Bootstrap

Partición sugerida

Mapa para convertir esta guía en templates y componentes reutilizables sin perder la identidad visual actual.

base.html

Head, fuentes, uni2-design-system.css, script de tema, navbar, bloque main, footer y scripts comunes.

includes/navbar.html

Marca, navegación, CTAs y versión responsive.

includes/footer.html

Íconos de contacto, ubicación y texto institucional.

components/media_list_item.html

Imagen o logo, título, descripción, metadata y etiqueta destacada para listados.

components/action_card.html

Ícono, título, descripción y link para accesos principales.

components/comparison_table.html

Tabla para comparar columnas de valores, estados o condiciones.

components/filter_bar.html

Búsqueda, selects, rango de fecha, chips activos y acción de limpiar.

components/metric_card.html

Indicadores de dashboard con número, contexto y color semántico.

forms/entity_form.html

Formulario Django renderizado con clases Bootstrap y mensajes de validación.
