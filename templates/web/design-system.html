¿Qué es esto?

Design System UNI2

Un design system es el conjunto de decisiones de diseño de un producto, documentadas y organizadas para que todo el equipo las use de forma consistente.

En lugar de inventar cada vez cómo se ve un botón, un color o una card, el design system define esas respuestas una sola vez. Todos los que construyen el sitio — diseñadores, desarrolladores, alumnos — trabajan desde el mismo punto de partida.

El design system de UNI2 está implementado en un único archivo CSS (uni2-design-system.css) y documentado en esta página.

La pirámide de capas

Cada capa se construye sobre la anterior. No se puede tener componentes sin primitivos, ni primitivos sin tokens.

TokensVariables CSS: colores, tipografía, forma, sombras y movimiento

La base de la pirámide son los tokens: los valores concretos que definen la identidad visual. Todo lo que está encima los usa, pero nunca los repite.

Movimiento

Las interacciones usan tres duraciones compartidas y una única curva. Esto mantiene consistentes botones, cards, menús y cambios de estado. Si el sistema operativo solicita movimiento reducido, las transiciones se desactivan y el carrusel comienza pausado.

Breadcrumbs

.uni2-breadcrumbs — navegación contextual compartida por las páginas de detalle. El catálogo usa el mismo partial productivo components/breadcrumbs.html.

{% include "components/breadcrumbs.html" with home_url="#componentes" parent_url="#componentes" parent_label="Productos y servicios" current_label="Fotocopias e impresiones" aria_label="Ruta de navegación de ejemplo" only %}
  • Se usa en páginas de detalle, no en la home ni en dashboards.
  • La página actual se muestra como texto y usa aria-current="page".
  • El separador › es decorativo; no se agrega un icono.
  • La ruta recomendada tiene entre dos y tres niveles y puede envolver en mobile.
  • El partial recibe parent_url, parent_label y current_label; Inicio se resuelve por defecto.
