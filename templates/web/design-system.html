Django + Bootstrap

Partición sugerida

Mapa para convertir esta guía en templates y componentes reutilizables sin perder la identidad visual actual.

base.html

Head, fuentes, `uni2-design-system.css`, script de tema, topbar, bloque main, footer y scripts comunes.

includes/topbar.html

Marca, navegación, CTAs y versión responsive.

includes/footer.html

Íconos de contacto, ubicación y texto institucional.

components/media_list_item.html

Imagen o logo, título, descripción, metadata y etiqueta destacada para listados.

components/action_card.html

Ícono, título, descripción y link para accesos principales.

components/comparison_table.html

Tabla para comparar columnas de valores, estados o condiciones.

components/filter_bar.html

Búsqueda, selects, rango de fecha, chips activos y acción de limpiar.

components/metric_card.html

Indicadores de dashboard con número, contexto y color semántico.

forms/entity_form.html

Formulario Django renderizado con clases Bootstrap y mensajes de validación.
