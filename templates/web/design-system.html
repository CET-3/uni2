¿Qué es esto?

Design System UNI2

Un design system es el conjunto de decisiones de diseño de un producto, documentadas y organizadas para que todo el equipo las use de forma consistente.

En lugar de inventar cada vez cómo se ve un botón, un color o una card, el design system define esas respuestas una sola vez. Todos los que construyen el sitio — diseñadores, desarrolladores, alumnos — trabajan desde el mismo punto de partida.

El design system de UNI2 está implementado en un único archivo CSS (uni2-design-system.css) y documentado en esta página.

La pirámide de capas

Cada capa se construye sobre la anterior. No se puede tener componentes sin primitivos, ni primitivos sin tokens.

TokensVariables CSS: colores, tipografía, espaciado, sombras

La base de la pirámide son los tokens: los valores concretos que definen la identidad visual. Todo lo que está encima los usa, pero nunca los repite.

Sistema visual UNI2

Includes reutilizables

Secciones completas extraídas a archivos propios. Se incluyen con {% verbatim %}{% include %}{% endverbatim %} en la home pública y en el panel de asociado.

base.html

Head, fuentes, uni2-design-system.css, script de tema, navbar, bloque main, footer y scripts comunes. Todas las páginas lo extienden.

includes/navbar.html

Marca, navegación, CTAs y versión responsive. Incluido desde base.html.

includes/footer.html

Íconos de contacto, ubicación y texto institucional. Incluido desde base.html.

includes/servicios_grid.html
