# Asociados

1. Un asociado puede ser de tipo asociado o adherente.
2. Si el tipo es asociado, debe tener un curso cargado. Si el tipo es adherente, no debe tener curso.
3. Los asociados participan de asambleas; los adherentes no.
4. Los asociados inactivos conservan sus datos, cuotas y pagos.
5. Solo los asociados activos generan nuevas cuotas.
6. No puede existir más de un asociado con el mismo DNI.
7. El número de asociado debe generarse automáticamente.
8. Un asociado puede existir sin usuario de acceso.
9. Al crear un asociado se puede crear también un usuario de acceso vinculado.
