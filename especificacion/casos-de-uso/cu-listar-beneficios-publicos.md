# CU-listar-beneficios-publicos

**Actor:** Visitante

**Flujo principal:**

1.  Ingresa a la home.
2.  Selecciona el acceso a beneficios.
3.  El sistema muestra los beneficios activos.
4.  El listado respeta el orden definido para publicación.
