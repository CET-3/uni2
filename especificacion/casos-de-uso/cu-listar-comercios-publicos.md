# CU-listar-comercios-publicos

**Actor:** Visitante

**Flujo principal:**

1.  Ingresa a la home.
2.  Selecciona el acceso a comercios adheridos.
3.  El sistema muestra los comercios publicados con su actividad comercial y beneficio vigente.
4.  El visitante puede consultar los datos públicos de contacto o presencia web disponibles.

**Reglas relacionadas:** [COMERCIO-002](/reglas/comercios.md#comercio-002), [COMERCIO-003](/reglas/comercios.md#comercio-003), [COMERCIO-005](/reglas/comercios.md#comercio-005), [COMERCIO-006](/reglas/comercios.md#comercio-006).

**Modelos afectados:** ActividadComercial, Comercio.
