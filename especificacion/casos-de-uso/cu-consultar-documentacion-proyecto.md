# CU-consultar-documentacion-proyecto

**Actor:** usuario del grupo `Equipo del proyecto`.

1. Inicia sesión y elige la experiencia de administración.
2. Abre Especificación o Design system desde sus accesos.
3. Navega el contenido y vuelve a la home.

**Resultado:** puede estudiar procesos, reglas y componentes visuales.

**Restricción:** el grupo no habilita admin técnico, asociados, contenidos,
finanzas ni auditoría.

**Pruebas:** abrir ambas herramientas; comprobar que Admin técnico no aparece;
intentar una URL operativa y recibir denegación.
