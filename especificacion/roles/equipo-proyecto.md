# Equipo del proyecto

El grupo `Equipo del proyecto` permite consultar la especificación funcional y
el design system desde la aplicación. Está pensado para estudiantes que
participan en análisis, diseño, desarrollo, pruebas o capacitación.

No concede acceso al admin técnico, asociados, cuotas, usuarios, contenidos ni
auditoría. Si una persona también cumple una función operativa, debe recibir
además el grupo correspondiente; los permisos se acumulan.
