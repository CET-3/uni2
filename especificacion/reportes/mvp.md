# Reportes MVP

En el MVP no se implementan dashboards analíticos ni reportes agregados. Las pantallas internas priorizan acceder a las tareas operativas: buscar asociados, cobrar cuotas, ver deudores y administrar períodos de cuota.

Los listados simples de deudores y cuotas se mantienen como pantallas operativas, no como tablero de métricas.
